種子承諾模型
每間 RGS 工作室都遇過的 6 個整合痛點
  1. Nonce 與扣款不同步 → 被指控吃單
  2. 免費旋轉和連消的子序號爆炸
  3. Client Seed 控制權爭議 — 營運商 vs. 玩家
  4. 離線玩家的種子揭露生命週期
  5. API 封包膨脹 — 每次旋轉都帶驗證資料
  6. GLI-19 認證與玩家輸入的衝突
FairSeal 種子承諾模型
一個 SDK，零生命週期管理 — Session 種子透過 drand 信標鎖定。無需種子輪換、揭露排程或 nonce 鏈。
天生防作廢 — 無順序性 nonce 鏈，就不存在需要解釋的缺口。作廢的旋轉只是未使用的衍生路徑。
樹狀衍生 — 免費旋轉與連消從父級旋轉索引衍生。無限深度，單一營運商交易。
精簡 API — 旋轉回應僅 { spinIndex, resultHash }。完整驗證透過 verify.fairseal.io。
雙模式 — Mode A：完整可驗證公平（加密貨幣 / Web3）。Mode B：GLI 安全審計模式（受監管市場）。同一 API，設定檔切換。
