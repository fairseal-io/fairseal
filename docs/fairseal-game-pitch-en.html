FairSeal Seed Commitment Model
One SDK, zero lifecycle management — Session seed locked via drand beacon. No seed rotation, no reveal scheduling, no nonce chains.
Void-proof by design — No sequential nonce chain means no gaps to explain. Voided spins are just unused derivation paths.
Tree derivation — Free spins and cascades derive from parent spin index. Unlimited depth, one Operator transaction.
Compact API — Spin response is just { spinIndex, resultHash }. Full verification via verify.fairseal.io.
Two modes — Mode A: full provably fair (crypto/Web3). Mode B: GLI-safe audit-only (regulated markets). Same API, config flag.
